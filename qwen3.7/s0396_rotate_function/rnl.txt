- The integer array parameter `nums` is not equal to the null literal.
- All values in the integer array parameter `nums` are greater than or equal to -100 and are less than or equal to 100.

- If the integer array parameter `nums` is equal to [4,3,2,6], the integer result is equal to 26.
- If the integer array parameter `nums` is equal to [100], the integer result is equal to 0.
